# ScreenClick — Complete Use Case Guide (15 Verticals)

> **Repositioning:** ScreenClick isn't just a QA tool — it's a **workflow evidence layer** for any team that needs to prove what happened on screen. All processing is on-device; no cloud, no analytics, no data custody issues.

---

## Core Repositioning Statement

**Old framing:** "Screenshot tool for QA teams"
**New framing:** "Instant, labeled, PDF evidence of any workflow — on-device, no cloud"

The labeled PDF export is the wedge. Every vertical below ultimately needs a *deliverable* — something to attach to a ticket, send to a regulator, upload to an LMS, or file with legal. ScreenClick produces that artifact in one session.

---

## Category 1 — Professional & Enterprise

### Vertical 1 — Compliance & Audit

**Personas:** Compliance officers, internal auditors, risk teams, legal ops

**Tagline:** *Tamper-proof, on-device workflow evidence for regulated processes*

#### Use Cases
- SOX, HIPAA, GDPR workflow documentation — prove a regulated process was followed correctly
- Audit-ready PDF trails ready for regulator submission
- Capturing consent and disclosure screens at exact moment of acceptance
- Policy adherence documentation — visual proof an employee followed a defined process
- Timestamped evidence of access controls and permission states
- Change management documentation — before/after states of system configurations
- Third-party vendor access monitoring documentation

#### Best Capture Modes
- **Process Record** — step-by-step labeled trail of every action
- **Timer mode** — periodic capture of system state over a session
- **Full Page** — long policy documents, full audit logs

#### Key Differentiator
On-device processing means sensitive compliance data never leaves the machine — no cloud upload, no third-party data custody. Critical for HIPAA, financial services, and legal environments.

## Landing Page Strategy

### Hero Positioning
Replace a single static hero with a vertical switcher:

> "I'm a ___" → [QA engineer] [compliance officer] [support lead] [L&D manager] [legal team] [researcher]

Copy and use cases adapt per selection. This directly maps buyer intent to product value.

### Three Strongest New Angles to Lead With

1. **Healthcare / MedTech** — PHI compliance is non-negotiable. On-device processing makes ScreenClick the only safe option for clinical workflows.
2. **Compliance / Audit** — enterprises pay significant budget for tamper-proof evidence. The on-device message is the closer.
3. **Knowledge Base / Docs** — L&D and technical writing teams recapture screenshots constantly. Process Record eliminates that overhead entirely.

### The On-Device Message
"No network. No analytics. No cloud." This is the #1 reason legal, finance, healthcare, and compliance buyers choose ScreenClick over Loom or cloud recorders. It should be a prominent trust badge across all regulated verticals — not buried in a features list.

## Competitive Differentiation Summary

| Competitor type | Their gap | ScreenClick advantage |
|---|---|---|
| Loom / screen recorders | Video = editing overhead, cloud storage, hosting cost | PDF = instantly shareable, no editing, no hosting |
| Browser snipping tools | No labeling, no PDF, entirely manual | Auto-labeled, structured, exportable in one session |
| Cloud screenshot tools | Data uploaded to third-party servers | 100% on-device, no custody issues |
| Enterprise compliance tools | Complex setup, expensive licensing | Chrome extension, no IT deployment needed |
| Manual documentation | Hours of writing and screenshot hunting | One walkthrough = complete labeled PDF guide |
