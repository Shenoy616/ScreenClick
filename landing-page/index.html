Privacy by design

Privacy isn't a feature.
It's the architecture.

Loom uploads your video. Cloud screenshot tools store your data on someone else's server. ScreenClick runs entirely in your browser — captures, PDF generation, and download all happen locally. That's why healthcare, legal, finance, and compliance teams trust it.

No network calls

ScreenClick makes zero HTTP requests. No API endpoints, no CDN, no telemetry beacons. Works offline after install.

No analytics or tracking

No Google Analytics, no Mixpanel, no session recording. We don't know you installed it, and we never will.

No cloud custody

Sensitive data never touches a third-party server. Critical for HIPAA, SOX, legal chain-of-custody, and PHI workflows.

No account required

Install from the Chrome Web Store and start capturing. No sign-up, no subscription, no identity tied to your captures.

Local storage only

Captures live in chrome.storage.local for the session, then become a PDF saved to your machine.

UTC attestation

Every capture stamped in UTC. Exported PDFs include a signed integrity manifest — SHA-256 hashes and ECDSA signature, computed on-device.

Chrome Web Store listing

Published on the Chrome Web Store with a minimal permission set. Every capture and export still runs on-device — no black-box SaaS, no opaque cloud pipeline.

    Common questions

    FAQ.

    Is ScreenClick safe for HIPAA, PHI, and patient data?

    Yes — by architecture, not by policy. ScreenClick makes no network calls, stores captures in local browser storage only, and builds PDFs on-device. Patient data never transits to a cloud server because there is no cloud component. This makes it suitable for EHR workflows, clinical training, and telehealth support where PHI is visible on screen.

    Does ScreenClick send my screenshots anywhere?

    No. Captures live in chrome.storage.local for the duration of the session and become a PDF on your machine when you click Stop and Save. Nothing leaves your browser. No analytics, no telemetry, no remote servers. This is the #1 reason legal, healthcare, compliance, and finance teams choose ScreenClick over Loom or cloud screenshot tools.

    Is ScreenClick on the Chrome Web Store?

    ScreenClick is listed on the Chrome Web Store. For now, clicking Add to Chrome on this page downloads a zip you can load unpacked in Chrome — same extension, same privacy guarantees. One-click install from the Store listing is coming soon.

    Will it capture pages behind login?

    Yes. ScreenClick captures whatever you can see in the active tab — logged-in dashboards, internal admin panels, staging sites. Chrome restricts chrome:// pages and the Web Store; everything else works.

    Are timestamps tamper-evident?

    Yes — on-device. Every capture is stamped in UTC (ISO 8601) at the moment it was taken. When you export, ScreenClick adds a final attestation page: SHA-256 hashes of each screenshot, a chained integrity manifest, and an ECDSA P-256 signature — all computed locally with zero network calls. That proves the PDF wasn't altered after export. Times still come from your system clock; for legally binding third-party timestamps (RFC 3161), pair with a trusted timestamp authority.

    How is this different from Loom?

    Loom produces video that needs editing, hosting, and cloud storage. ScreenClick produces a labeled PDF in one session — instantly shareable, printable, and attachable to tickets or audit packs. No upload time, no subscription, no custody concerns.

    What about Firefox or Safari?

    Chrome and Chromium-based browsers (Edge, Brave, Arc) only for now.
