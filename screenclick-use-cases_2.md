# ScreenClick — Expanded Use Case Guide

> **Repositioning:** ScreenClick isn't just a QA tool — it's a **workflow evidence layer** for any team that needs to prove what happened on screen. All processing is on-device; no cloud, no analytics, no custody issues.

---

## Core Repositioning Statement

**Old framing:** "Screenshot tool for QA teams"
**New framing:** "Instant, labeled, PDF evidence of any workflow — on-device, no cloud"

The labeled PDF export is the wedge. Every vertical below ultimately needs a *deliverable* — something to attach to a ticket, send to a regulator, upload to an LMS, or file with legal. ScreenClick produces that artifact in one session.

---

## Vertical 1 — QA & Testing (Core)

**Personas:** QA engineers, SDET, manual testers, product managers

**Tagline:** *From test run to evidence PDF in one session*

### Use Cases
- Regression evidence across releases — visual proof of what passed or failed
- Acceptance criteria documentation — capture the exact state that satisfies a requirement
- Cross-browser visual diff capture — same flow, different environments
- Load/stress test visual state capture using Timer mode (periodic screenshots)
- End-to-end test step documentation with Process Record auto-labeling
- Release sign-off evidence PDFs for stakeholder approval
- Bug reproduction packets — attach labeled PDF to tickets instead of describing steps

### Best Capture Modes
- **Process Record** — auto-labels each click/form fill for test step documentation
- **Timer mode** — periodic state capture during load tests
- **Full Page** — capture full error pages or long data tables
- **Visible Tab** — fast capture of unexpected UI states

### Best Capture Modes

## Landing Page Strategy

### Hero Positioning
Replace a single hero with a vertical switcher:

> "I'm a ___" → [QA engineer] [compliance officer] [support lead] [L&D manager] [legal team]

Copy and use cases adapt per selection. This is a proven SaaS conversion pattern.

### Three Strongest New Angles to Lead With

1. **Compliance/Audit** — enterprises pay significant budget for tamper-proof evidence. On-device processing is the key message.
2. **Training/L&D** — L&D teams need updated guides constantly; Process Record makes this effortless. No video editing required.
3. **Legal/eDiscovery** — on-device = no cloud custody = legally cleaner evidence chain. Unique differentiator vs. Loom or cloud recorders.

### The On-Device Message
"No network. No analytics. No cloud." is the #1 reason legal, finance, and compliance buyers choose ScreenClick over alternatives. This should be a prominent trust signal across all regulated verticals — not buried in a features list.

| Competitor type | Their gap | ScreenClick advantage |
