Settings

Keyboard Shortcuts

Two shortcuts are available. To rebind them, open chrome://extensions/shortcuts (Chrome does not let extensions set keys directly).

Start capturing or stop and save PDF
Capture screenshot (during recording only)

On Mac, use the Control key (not Command) — the same modifier as Jam’s working shortcuts. Toggle-start defaults to Visible Tab; use the side panel to pick Process Record or Screen mode.

Standard Triggers

Apply to Visible Tab mode.

Process Record Mode

Triggers that fire while in Process Record mode. Each capture becomes a numbered Point in the PDF.

Screen or Window mode

Desktop screenshots of your monitor or an app window.

Image Quality

Lower values produce smaller PDFs but visibly compressed screenshots.
