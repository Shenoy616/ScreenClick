Settings

Standard Triggers

Apply to Visible Tab, Full Page, and Entire Screen modes.

Process Record Mode

Triggers that fire while in Process Record mode. Each capture becomes a labeled step in the PDF.

Image Quality

Lower values produce smaller PDFs but visibly compressed screenshots.

Keyboard Shortcuts

Three shortcuts are available. To rebind any of them, open chrome://extensions/shortcuts (Chrome does not let extensions set keys directly).
